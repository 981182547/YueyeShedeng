# 车辆图片放这里

把那张越野车实拍图放进本目录，App 主页就会用它当背景，
灯位光点会自动叠在车上对应的位置。

- 首选文件名：`car.png`
- 也可以叫别的名字：`.png` / `.jpg` / `.jpeg` / `.webp` 都行，
  程序会自动扫这个目录，取第一张图来用。
- 图片的宽高比是运行时从图片本身读出来的，不用在代码里填。

## 灯位对不上怎么办

灯位坐标是照着那张 Jeep 图量的，写在 `lib/models/lamp.dart` 的 `kLamps` 表里。
`x` / `y` 是相对坐标（0~1，相对图片左上角），换了别的车图就改这张表，
其它代码都不用动。

> 这个 README 同时用来占位：pubspec.yaml 里声明了 `assets/images/`，
> 空目录 git 不会跟踪，推到 GitHub 后 CI 会因为找不到目录而构建失败。
